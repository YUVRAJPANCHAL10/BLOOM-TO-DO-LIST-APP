# 🌸 Bloom To-Do List

A simple To-Do List desktop application built with Python. This is my **first Python project**, created to practice programming fundamentals and learn how to build a functional application.

## ✨ Features

- ➕ Add new tasks
- 📋 View all tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔢 Display the number of pending tasks
- ⚠️ Handle invalid inputs and empty tasks
- 🎨 Aesthetic desktop interface with pastel colours and styled widgets
- 🖱️ Interactive buttons and task checkboxes

## 🛠️ Tech Stack

- **Python** — Core programming language
- **Tkinter** — Desktop graphical user interface
- **Git & GitHub** — Version control and project hosting

## 📁 Project Structure

```text
todo_app/
├── main.py       # Tkinter GUI
├── backend.py    # Task management logic
└── README.md
```

## 🚀 How to Run

### Prerequisites

- Python 3 installed
- Tkinter available in your Python installation

### Steps

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd todo_app
   ```

3. Run the application:

   ```bash
   python main.py
   ```

No additional Python packages are required for the current version on a standard Windows Python installation.
